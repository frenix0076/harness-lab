# Projet harness-lab

## Commandes stables
- Tests : `npm test`
- Vérification : `npm run verify`

## Règles stables
- Les montants métier sont exprimés en cents entiers.
- Ne modifie pas un comportement métier sans adapter ou ajouter la preuve déterministe correspondante.
- Le ticket et les tests font foi ; la conversation n'est pas une source de vérité.
- Avant de conclure une tâche, exécute la vérification adaptée au changement.
